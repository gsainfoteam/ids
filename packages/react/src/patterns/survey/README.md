# 설문

Storybook `Patterns/PC/Survey` 와 `Patterns/Mobile/Survey`. 진행 막대와 단일 선택, 복수 선택, 별점, 슬라이더, 서술형 문항을 갖춘 설문입니다.

- **쓰인 컴포넌트.** Progress, RadioGroup, CheckboxGroup, Rating, Slider, TextArea, Card, Badge, Empty
- **폭에 따라.** 한 열입니다.
- **알아둘 것.**
  - 문항마다 `<fieldset>` 과 `<legend>` 로 묶습니다.
  - `Rating` 의 0 은 "고르지 않음" 입니다.
