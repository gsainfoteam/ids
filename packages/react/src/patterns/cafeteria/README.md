# 학식

Storybook `Patterns/PC/Cafeteria` 와 `Patterns/Mobile/Cafeteria`. 식당 탭, 요일 전환, 메뉴 카드, 평가, 알레르기 필터를 갖춘 학식 화면입니다.

- **쓰인 컴포넌트.** Tabs, ToggleGroup, Toggle, Card, Image, Badge, Rating, Chip, Alert, toast
- **폭에 따라.** 메뉴 카드는 `sm` 2열, `lg` 3열입니다.
- **알아둘 것.**
  - 평가는 `Rating` 을 누르는 즉시 `onValueChange` 로 보냅니다.
