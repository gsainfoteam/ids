# 택시 합승

Storybook `Patterns/Carpool`. 출발지와 목적지 전환, 날짜 필터, 합승 카드, 합승을 여는 서랍을 갖춘 화면입니다.

- **쓰인 컴포넌트.** Select, IconButton, DateField, TimeField, NumberField, Chip, Card, Progress, AvatarGroup, Drawer, Empty, toast
- **폭에 따라.** 한 열이고, 출발과 도착은 `sm` 부터 한 줄에 놓입니다.
- **알아둘 것.**
  - 합승을 여는 폼은 `Drawer side="bottom"` 안에 둡니다.
