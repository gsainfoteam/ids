# 청원

Storybook `Patterns/PC/Petition` 와 `Patterns/Mobile/Petition`. 목표 인원까지의 진행, 동의, 진행 단계, 답변 대기, 동의한 사람들의 말, 비슷한 청원을 갖춘 화면입니다.

- **쓰인 컴포넌트.** Breadcrumb, Badge, Stepper, Empty, Progress, Card, Item.Group, Button, IconButton, toast
- **폭에 따라.** `lg` 부터 동의 카드가 오른쪽에 붙고 따라옵니다.
- **알아둘 것.**
  - 동의하면 버튼이 `soft` 로 바뀌고 수가 하나 늘어납니다.
