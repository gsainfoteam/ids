# 서비스 소개

Storybook `Patterns/Landing`. 메뉴, 큰 제목, 함께하는 단체, 기능, 후기, 자주 묻는 질문, 행동 유도 띠, 바닥글을 갖춘 소개 페이지입니다.

- **쓰인 컴포넌트.** Button, Badge, Marquee, Card, Avatar, Accordion, Menu, Divider
- **폭에 따라.** 기능 카드는 `sm` 2열, `lg` 3열입니다. 상단 메뉴는 `md` 부터 보입니다.
- **알아둘 것.**
  - 함께하는 단체는 `Marquee` 로 흐르고, 동작 줄이기 설정이면 멈춥니다.
  - 행동 유도 띠는 `primary` 바탕에 `on-primary` 글자입니다.
