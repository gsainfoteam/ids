## 규칙

- 한 폴더에 `<이름>.stories.tsx` 와 README 를 둡니다. 화면은 다른 스토리처럼 `render` 에 통째로 적습니다.
- 스토리는 `parameters: { canvasPadding: false }` 로 데코레이터의 `p-8` 을 빼고 캔버스를 채웁니다.
- 레이아웃은 Tailwind 유틸리티, 색은 IDS 토큰입니다. 테스트 화면인 414px 부터 짜고, 가장 바깥 요소에 `break-keep` 을 줘서 한국어가 낱말 단위로 줄을 바꿉니다.
- `ghost` 는 쓰지 않습니다. 버튼은 `outline` 이나 `soft`, 기본값이 ghost 인 Toggle, IconToggle, Empty, Item.Group 도 variant 를 적습니다.
- 데이터는 모듈 위 상수입니다. 날짜와 숫자를 고정해 서버와 클라이언트 렌더가 같습니다.
- IDS 에 없는 것이 필요하면 패턴 코드로 만들지 않고 컴포넌트로 요청합니다.
- `tests/stories-patterns.test.tsx` 가 모든 패턴을 라이트와 다크에서 그리고 axe 를 돌립니다. SSR, hydration, 영어 번역 검사도 다른 스토리처럼 받습니다.
