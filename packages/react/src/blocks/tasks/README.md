# Tasks

Storybook `Blocks/Tasks/*`. 할 일 화면 두 가지입니다.

| 구현    | 화면                                                                                       |
| ------- | ------------------------------------------------------------------------------------------ |
| `Table` | 검색, 상태와 우선순위 필터, 여러 행 선택과 한꺼번에 끝내기, 정렬과 페이지가 있는 할 일 표.      |
| `Board` | 할 일, 하는 중, 끝남 세 열의 카드 보드. 카드 메뉴에서 상태를 고르면 그 열로 옮겨 간다.          |

- **쓰인 컴포넌트.** DataTable, Badge, Avatar, Empty, TextField, Select, Button, Card, IconButton, Menu, Spacer, toast
- **알아둘 것.**
  - 상태는 색이 있는 `Badge` 입니다. 할 일은 neutral, 하는 중은 info, 끝남은 success 입니다.
  - 표의 선택은 `rowSelection` 으로 제어하고, 한꺼번에 끝낸 뒤 선택을 비웁니다.
  - 필터를 걸면 필터 지우기 버튼이 나타납니다.
  - 보드는 끌어서 옮기지 않습니다. 끌기로 옮기는 칸반 컴포넌트는 아직 없고, 메뉴의 `Menu.RadioGroup` 이 상태를 바꿉니다.
  - 좁은 화면에서는 세 열이 위아래로 쌓입니다.
