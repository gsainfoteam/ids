# FAQ

Storybook `Blocks/FAQ/*`. 자주 묻는 질문 섹션 두 가지입니다.

| 구현        | 화면                                                                               |
| ----------- | ---------------------------------------------------------------------------------- |
| `Accordion` | 가운데 제목, 하나씩 여는 질문 목록, 아래에 인포팀에 묻는 카드.                        |
| `Columns`   | 왼쪽은 제목과 도우미 버튼, 오른쪽은 주제 탭과 여러 개를 함께 열 수 있는 질문 목록.     |

- **쓰인 컴포넌트.** Accordion, Card, Tabs, Button
- **알아둘 것.**
  - Accordion 은 `type="single"` 로 하나만 열고, 첫 질문을 `defaultValue` 로 열어 둡니다.
  - Columns 는 `type="multiple"` 이라 여러 답을 같이 펼쳐 비교할 수 있습니다.
