# Footer

Storybook `Blocks/Footer/*`. 페이지 맨 아래 바닥글 두 가지입니다.

| 구현      | 화면                                                                                         |
| --------- | -------------------------------------------------------------------------------------------- |
| `Columns` | 로고와 소식 받기 입력, 링크 세 묶음, 저작권과 언어 고르기, 블로그와 메일 버튼.                  |
| `Simple`  | 한 줄. 왼쪽 저작권, 오른쪽 세로선으로 나눈 링크 셋. 좁으면 두 줄로 쌓인다.                     |

- **쓰인 컴포넌트.** Avatar, TextField, Button, IconButton, Select, Divider, Skeleton, toast
- **알아둘 것.**
  - 바닥글 링크는 꾸미지 않은 `<a>` 입니다. 목록 안의 링크라 글 속 링크처럼 밑줄이 없어도 구별되고, 글자색은 둘레를 따릅니다.
  - 링크 사이의 세로선은 `Divider orientation="vertical"` 입니다.
  - 위의 본문은 `Skeleton` 이고, 바닥글과 본문 사이의 선은 `Divider` 입니다.
