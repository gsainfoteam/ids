# Hero

Storybook `Blocks/Hero/*`. 첫 화면 맨 위의 소개 두 가지입니다.

| 구현       | 화면                                                                                            |
| ---------- | ----------------------------------------------------------------------------------------------- |
| `Centered` | 가운데 제목, 두 버튼, 쓰는 사람 수. 아래에 공지, 셔틀, 학식 카드로 서비스를 미리 보여 준다.        |
| `Split`    | 왼쪽은 제목과 할 수 있는 일, 오른쪽은 예시 질문 칩을 누르면 답이 바뀌는 도우미 카드.              |

- **쓰인 컴포넌트.** Button, AvatarGroup, Avatar, Badge, Card, Item, Progress, Chip, Table
- **알아둘 것.**
  - 미리 보기는 사진 대신 실제 IDS 카드로 짭니다. Centered 의 미리 보기는 데이터가 아닌 그림이라 `aria-hidden` 이고, 안에 누를 것을 두지 않습니다.
  - Split 의 미리 보기는 칩을 눌러 바꿀 수 있는 진짜 조작이라 숨기지 않습니다.
  - 맨 위 알림 링크와 버튼은 `Button asChild` 로 감싼 `<a>` 입니다.
