# Shuttle

Storybook `Blocks/Shuttle/*`. 셔틀 화면 두 가지입니다.

| 구현    | 화면                                                                                           |
| ------- | ---------------------------------------------------------------------------------------------- |
| `Board` | 노선 탭, 다음 셔틀까지 남은 시간과 알림, 오늘 시간표, 정류장별 도착 시간.                           |
| `Stop`  | 정류장 하나에 곧 오는 셔틀. 정류장 칩으로 바꾸고, 즐겨찾기와 새로 고치기가 있다. 휴대폰에 맞춘 폭. |

- **쓰인 컴포넌트.** Tabs, Card, Badge, Progress, Switch, Label, Table, Stepper, Alert, Chip, Item, IconToggle, Button, toast
- **알아둘 것.**
  - 지금 시각은 `12:14` 로 고정합니다. 앱에서는 서버 시각을 받아 1분마다 다시 그립니다.
  - 다음 차는 `Table.Row selected` 로 깔고, 지난 차는 흐리게 칠하지 않고 "떠남" 배지를 붙입니다.
  - 정류장은 `Stepper` 의 현재 단계를 첫 정류장에 두어, 셔틀이 떠나는 곳을 보입니다.
  - 알림 줄은 `Card.Footer` 의 `border-t` 로 나눕니다.
