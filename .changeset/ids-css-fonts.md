`@gsainfoteam/ids-css` now ships the IDS fonts, Pretendard GOV (variable, dynamic subset) and
Geist Mono (variable), with their woff2 files and OFL licenses inside the package. The app's
bundler emits the files; no CDN or font package is needed. `@gsainfoteam/ids-css/no-fonts.css` is
the same CSS without the fonts.
