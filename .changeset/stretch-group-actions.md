- `Tabs.List stretch` shares the list's width between horizontal tabs.
- `Field.Group` stacks Fields; with `orientation="horizontal"` they share one label column through
  subgrid, so every input starts at the same place. Fields inside take the group's orientation.
- A bare icon in `Item.Actions` takes the icon size and muted color, like `Item.Media`, for the
  chevron at the end of a link row.
