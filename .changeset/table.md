Add `Table`, the native table parts (`Table.Header`, `Body`, `Footer`, `Row`, `Head`, `Cell`,
`Caption`) styled for IDS inside a ScrollArea, so a wide or height-capped table scrolls with IDS
bars. It takes `variant` (`outline` / `ghost`), `size`, `layout` (`auto` / `fixed`), `striped`,
`highlightOnHover` and `stickyHeader`. Rows step up the neutral ladder for stripes, hover and
`selected`, and `Table.Head` sets `scope` from its section.
